# 整理流程

## 1. 读取与理解

读用户给的文本，判断它的结构：哪些是标题、哪些是列表、哪些是表格数据、哪些是正文段落。

## 2. 规范化

- **标题**：按层级加 `#`/`##`/`###`，同级标题层级一致。
- **列表**：无序用 `-`，有序用 `1.`；嵌套用两个空格缩进。
- **表格**：对齐成标准 Markdown 表格，表头与分隔行齐全。
- **代码/命令**：用反引号或围栏代码块包裹。
- **清理**：合并多余空行（最多一个空行），去掉行尾空格。

## 3. 输出

只输出整理后的 Markdown，不要加额外解释。

## 输入参数

要整理的文本：`${ARGUMENTS}`
