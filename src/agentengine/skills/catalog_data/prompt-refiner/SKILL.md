# 提示词优化流程

## 1. 诊断原始需求

指出原始描述里缺什么：目标是否明确、有没有约束、期望输出格式是否说清、有没有示例。

## 2. 重写

产出一版结构化提示词，包含：

- **角色/目标**：要 AI 扮演什么、达成什么。
- **输入**：会给什么材料。
- **约束**：长度、语气、必须/禁止做的事。
- **输出格式**：明确的结构（列表/表格/JSON/段落）。
- **示例**（可选）：一个期望输出的样例。

## 3. 说明改动

简要说明你改了什么、为什么这样更好。

## 输入参数

用户的原始需求或待优化提示词：`${ARGUMENTS}`
