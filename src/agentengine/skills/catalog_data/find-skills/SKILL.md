# 技能发现流程

## 1. 理解诉求

把用户的需求归纳成一个能力关键词（如"翻译""排版""数据分析""爬网页"）。

## 2. 匹配技能

对照技能市场已有的技能，挑出最相关的 1~3 个，说明：

- 技能名与一句话能力描述。
- 为什么匹配用户的需求。
- 安装后怎么用（在对话里选中该技能即可）。

## 3. 没有匹配时

如果市场里没有合适的，明确告诉用户"暂无现成技能"，并建议：

- 用通用对话直接处理，或
- 用"Skill Creator"思路自建一个技能（frontmatter + 流程说明）。

不要编造不存在的技能名。

## 输入参数

用户想实现的功能：`${ARGUMENTS}`
