# 合规审查流程

## 1. 通读全文

先理解文本的用途和场景（营销文案 / 合同 / 公告 / 隐私说明），不同场景的红线不同。

## 2. 逐条标注风险

对发现的每个风险点，给出：

- **位置**：引用原文片段。
- **问题**：违反了什么（夸大宣传、绝对化用语、隐私越界、误导性承诺等）。
- **依据**：为什么算风险（常识性合规原则即可，不编造具体法条号）。
- **建议**：怎么改更稳妥。

## 3. 总评

最后给一个整体风险等级（低/中/高）和优先处理的前 3 项。

## 重要

- 不编造法律条款编号；不确定的依据要说明是"一般性合规建议"。
- 这是辅助审查，不替代专业法务意见——在结论里提醒用户。

## 输入参数

待审查文本：`${ARGUMENTS}`
