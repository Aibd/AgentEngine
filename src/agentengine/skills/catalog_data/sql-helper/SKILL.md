# SQL 生成流程

## 1. 澄清表结构

如果用户没给表结构，先列出你假设的表名与关键字段，并说明假设。结构不清时宁可问，不要硬猜。

## 2. 生成查询

写出规范 SQL：

- 关键字大写，缩进清晰。
- 显式列名，避免无意义的 `SELECT *`。
- 用别名提升可读性。
- 注意 `JOIN` 条件、`GROUP BY` 与聚合的搭配、`NULL` 处理。

## 3. 解释与提醒

- 逐子句说明作用。
- 指出潜在性能点（缺索引、全表扫描）与边界情况。

## 输出格式

```sql
-- 查询
SELECT ...
```

后跟简要解释。

## 输入参数

用户的查询需求：`${ARGUMENTS}`
