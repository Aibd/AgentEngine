# 摘要流程

按以下三步执行，**不要跳步**：

## 1. 抓主旨

通读全文，先用一句话回答："这段内容到底在说什么。" 不要急着列细节。

## 2. 列要点

提炼 3~7 个关键要点，每个要点一行，遵循：

- 只保留有信息量的点，去掉铺垫和重复。
- 保留关键数字、结论、专有名词。
- 按重要性排序，不是按出现顺序。

## 3. 一句话结论

最后给一句"如果只能记住一句话"的结论。

## 输出格式

```
**主旨**：<一句话>

**要点**：
- ...
- ...

**结论**：<一句话>
```

## 输入参数

用户要总结的内容或诉求：`${ARGUMENTS}`
