# 会议纪要流程

## 1. 通读记录

读完原始记录，分清哪些是讨论、哪些是结论、哪些是待办。

## 2. 结构化

按固定结构归纳：

- **决议**：会上达成的明确结论。
- **待办**：每条带上 `负责人` 和 `截止时间`（没有就标"待定"）。
- **风险/分歧**：未解决的问题或不同意见。
- **下一步**：下次推进的动作或会议安排。

## 3. 输出

```
## 会议纪要

**决议**
- ...

**待办**
- [ ] <事项> — 负责人：<谁> — 截止：<时间>

**风险/分歧**
- ...

**下一步**
- ...
```

只保留有结论价值的信息，去掉闲聊。

## 输入参数

原始会议记录：`${ARGUMENTS}`
