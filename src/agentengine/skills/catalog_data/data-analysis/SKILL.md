# 数据分析流程

## 1. 摸清数据

先看清楚字段：有哪些列、各列含义、数据量、时间范围。指出明显的数据质量问题（缺失、异常值、单位不一致）。

## 2. 指标诊断

围绕用户关心的目标，挑核心指标计算：

- 规模类：总量、均值、占比。
- 趋势类：环比、同比、增长率。
- 结构类：分组对比、Top N、分布。

## 3. 趋势与归因

不要只报数字，要解释"为什么"：哪个分项在涨/跌、贡献多少、是否异常。

## 4. 产出报告

最终回答必须包含：

- **结论先行**：3 句话内说清最重要的发现。
- **关键指标**：表格或要点列出核心数字。
- **趋势分析**：变化方向 + 归因。
- **风险/建议**：基于数据的下一步建议。

格式用 Markdown，标题层级 `##`。

## 输入参数

用户的分析诉求与数据上下文：`${ARGUMENTS}`
