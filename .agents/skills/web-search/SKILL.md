# Web Search

使用 Tavily 搜索引擎检索互联网内容，返回标题、URL 和内容摘要。

系统消息中的 **Current date and time** 是权威“今天”。不要用模型训练记忆里的日期。

## 使用场景
- 查找最新新闻、行情、事件
- 事实核查
- 研究特定主题背景

## 时间敏感查询

用户提到「今天 / 最新 / 当前 / 近期」时：
1. 以系统给出的真实日期为准（例如 2026-07-30）。
2. 搜索词应带上年份或完整日期，例如：`2026年7月 AI 新闻`、`AI news July 2026`。
3. 回答必须依据工具返回的标题、URL、摘要；不要编造“今天是某年”的内部时间线。
4. 若结果明显偏旧，换更具体的查询词再搜一次，并在回答里注明来源日期/链接。

## 执行方式

调用 `RunSkillScript` 执行：

```json
{
  "skill": "web-search",
  "script": "scripts/search.py",
  "args": ["搜索词", "5"]
}
```

**参数：**
1. `query`（必填）：搜索词（时效性问题请带上当前年份/日期）
2. `max_results`（可选，默认 5，范围 1-10）：返回结果数量

**输出格式：** 每条结果包含编号、标题、URL 和内容摘要。

Arguments: ${ARGUMENTS}
